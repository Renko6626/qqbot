# 插件基础设施增强

2026-10-24，用户确认A方案后实现。仍为一个NoneBot容器、多个插件模块、单JSON配置。没有迁移旧AI/RAG、模型或新增数据库/独立管理服务。

## 功能

- 网页进程重启：认证+写请求头校验后返回202，再发送SIGTERM正常退出，Docker现有unless-stopped策略拉起。页面检查启动时间是否改变，约30秒后尚未确认恢复则提示刷新或去Coolify，不重复发重启请求。
- 群权限：每插件允许的群，每群选择全群成员或指定用户。显式空名单拒绝全部用户。
- 私聊权限：关闭、全部用户或指定用户；与群名单分开。旧配置缺少新字段时保持原行为，加载不会重写配置文件。
- 宿主使用NoneBot响应器运行前钩子统一授权，不再要求业务插件逐命令挂白名单装饰器。未知无作用范围事件不当私聊放行。
- 参数表单：文本、数字、布尔、枚举和简单列表，使用插件Pydantic声明与校验。加载状态区分实际结果、错误和本次启动后的加载选择变更。
- 按群查看已有配置，权限预览显示运行时实际允许/拒绝原因；没有另建权限表或多层继承。
