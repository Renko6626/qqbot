# NapCat 部署计划

已确认：同一 Coolify 项目内，NapCat 与后续功能容器作为独立资源管理；本次只创建项目和 NapCat。无需选择机器人框架。

1. 核对官方镜像、持久化目录、WebUI 与 OneBot 初始化方式。
2. 创建 QQ Bot 项目和 production 环境，创建单容器 NapCat Compose 服务。
3. 固定官方镜像版本及 digest，持久化 QQ/config/plugins；管理页只映射 127.0.0.1:6099，OneBot 不发布宿主端口。设置随机 WebUI/OneBot 令牌；Docker 日志轮转。
4. 通过 Coolify 启动，检查容器、HTTP 管理页、端口绑定和其他容器状态。QQ 扫码及消息收发由用户后续操作。

不新增机器人框架、日志平台、数据库、自动升级或备份调度。运行日志使用 Coolify 原生入口；消息/接口审计需求后续明确。
