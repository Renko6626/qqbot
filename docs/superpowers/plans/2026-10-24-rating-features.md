# 手动识别与自动监测实施计划

**目标：** 两个独立受管理插件共用图片下载、cutoff、预处理和单例ORT引擎。

**已确认方案：** 手动保留`/色图识别`；自动仅在`r15+r18 >= 0.8`时保存并回复。自动回复文案待用户提供，配置为空时只保存。每个插件独立开关、白名单、群覆盖和日志。文件存储原图和同名JSON，按群和UTC日期组织。

**边界：** 不新增容器、数据库、队列或自动群管理动作；不部署VPS。保持现有像素/下载限制和透明图处理规则。新插件默认关闭。
