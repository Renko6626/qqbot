# NoneBot 管理页实施计划

依据：`docs/nonebot-design.md`，技术方案已在对话中确认。单进程、单 JSON 配置、FastAPI 管理页、Coolify 管理进程；不迁移重型 AI/RAG，不新增恢复队列、状态机或数据库。

- [x] 实现静态插件目录、配置模型、保存及群/私聊授权；测试关闭、群范围、持久化及加载状态改变需重启的行为。
- [x] 实现管理认证、状态查询和单插件配置接口；验证未认证无法读取或修改，非法参数不写入，合法保存能影响授权。
- [x] 注册 OneBot 与两个基础插件；实际启动并检查加载结果，界面显示实际连接及加载失败信息。
- [x] 实现原生管理页，检查 JS 语法并截图查看桌面与手机布局；不自动交互。
- [x] 锁定依赖、构建镜像，通过 Coolify 创建独立资源，持久化配置，连接现有 NapCat 网络。验证 HTTP/健康/只读连接；域名等待用户 DNS 后接入。
- [x] 记录实际验证与尚未迁移功能，更新运维文档。
