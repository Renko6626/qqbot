# Vue 管理页与紧凑布局

## 已确认路线

用户确认迁移 Vue 3 + Vite + TypeScript，同时将管理页调整得更紧凑，并要求写计划后直接实施。继续使用现有 Python 服务、HTTP Basic、API 和容器，不增加独立前端服务、路由库、状态库或 UI 组件库。另一个方案是仅压缩原生页面；用户选择组件化迁移，减少后续手工 DOM 和状态同步。

## 范围与边界

前端源码放 `web/`。职责为应用壳与状态、插件设置、群权限与群参数、schema 参数编辑、按群查看、图集管理和权限预览。API 调用和表单值转换放简短 TypeScript 模块；状态由 Vue 组件管理。

保留所有现有操作：插件启用与启动加载、群及成员范围、私聊范围、公共参数、稀疏群覆盖、按群查看、未保存提示和切换时草稿保留、刷新丢弃确认、加载状态及待重启提示、权限预览、进程重启与原有恢复等待、图集创建上传查看与删除。

群参数只提交被勾选覆盖的字段，取消勾选恢复继承。false、0、空列表、null 和原始字符串保持语义；非法/不支持的 schema 阻止保存。群号和 QQ 号保留字符串，提交范围和白名单语义不变。图集和插件配置互相独立，不增加保存队列、恢复机制或持久化草稿。

## 布局

延续原蓝灰配色：背景 #f2f4f7、正文 #17233b、主色 #315bc8、边线 #dfe4ec、次级文字 #637086；继续使用系统中文字体。

顶栏约 56px，集成连接状态、刷新、进程操作。桌面采用窄侧栏 + 内容区，插件选择保留目录；手机以紧凑下拉选择代替整块目录。插件表单和参数桌面双列，次要权限、说明和进程细节默认收起。图集选择/刷新/上传集中到工具栏，新建图集按需展开，缩略图显示来源和时间。优先节省垂直空间，避免展示与当前操作无关的大区域。

## 构建与交付

Vite 将产物写入 `qqbot/static/`，该目录改为生成目录并 Git 忽略，原生实现删除。后端仍从该目录返回首页；资产读取改为仅允许生成的 JS/CSS 文件，保持认证且禁止目录逃逸。本地先 `npm ci --prefix web && npm run build --prefix web` 后启动 Python，也可使用 Vite 开发代理。

Docker 新增 Node 构建阶段，复制构建产物到原 Python 运行镜像；运行时不需要 Node，不增加端口。沿用现有容器发布流程，本次不操作服务器、不部署。
